# 概述

本系列文本旨在记录一些自己在 [MC百科](https://www.mcmod.cn/) 编辑时积累的经验，供自己及其他人以后参考。
主要包含以下内容：
1. 编辑规范；
   - [[MC百科主站编辑规范]]；
   - [[主站通用命名规则]]；
   - [[模组收录规则]]；
   - [[整合包收录规则]]；
   - [[模组元素、模组关系]]；
   - [[批量添加资料]]；
1. 怎么写模组简介；
  - [[寻找模组]]；
  - [[正文编写]]；
1. 怎么写资料简介；
2. （暂定）

> 导入注意：全仓库为 *Obsidian 格式*。

> 写百科的话，主要就两个要求：
> - 游戏理解过关；
> - 英语好。
# 为什么写这个东西

现在百科有了审核助理，自己也成为了其中一员，但是点审核助理的过程中发现大量的日经问题：
```
审核助理高血压日常：  
一眼望不到头的列表；诡异的排版；各种乱七八糟日经问题（比如句末没句号、一堆半角标点、一堆多余空行）；高血压新增模组（模组本身不行、正文排版奇差、没有 ModID / 作者 / 链接、正文机翻或者严重 AI 味或者非常主观 / 第一人称 / 不正式、乱加标签和关键词、封面糊等等），而且添加模组基本上一直是问题最大的；重写了整个正文结果还不如不重写的；通篇 Markdown 的；资料稍微好一点，但是仍然会有图标模糊 / 没有注册名 / 没有最大堆叠这种日经问题。  
突然也在想，百科会不会给新人一种“规矩太多”的感觉……反正现在审核助理后台满眼都是“检查”和“退回”。
```
此前，站长表示有计划制作百科编辑指南，因此这个计划便有了复活的意义。
现在再回去看，发现很多地方不太详细，处于懂的人不用看、不懂的人看不懂得状态，而且语气过于奇怪（像 DeepSeek写的），因此重新修改一下。

>*本指南的所有文字均为手写。*
