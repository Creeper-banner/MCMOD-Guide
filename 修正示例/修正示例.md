# 一根绳子，所有连接
万物皆可绳是一个 NeoForge 模组，把原版拴绳变成万能连接工具
红石信号、能量、物品、流体——全靠一根绳子

---

## 绳子种类
用对应材料右键绳子即可原地转换或升级

|   |   |   |   |
|---|---|---|---|
|类型|转换材料|升级材料|效果|
|红石|红石块|—|端点间双向红石信号|
|能量 (FE)|铁块|红石块|FE 传输|
|物品|漏斗|箱子|物品运输|
|流体|炼药锅|桶|容器间流体传输|
|压力 (气体)|钢块|强化合金|Mekanism 化学/气体传输|
|热量|铜块|强化合金|Mekanism 热量传输|
|AE   网络|福鲁伊克斯块|16³ 空间组件|AE2 频道桥接|

### 能量绳
- 基础吞吐：tier 0 = 256 FE/t，每级翻倍 
- 最大 tier 可配置（默认 30）    
- 通电绳子发光并喷发粒子    

### 物品/流体绳
- 用转换材料点击端点切换提取方向
- tier 0: 1 个物品 / 1000 mB 每次；每级翻倍
- 栅栏结多绳连接自动轮询分流
    

---

## 用法
### 放置绳子
右键方块面 → 设置第一锚点。右键另一方块 → 创建连接
锚点可贴在任意方块面，不限于栅栏

### 延伸长度
新绳子：点击方块设置第一锚点后，**再次点击同一锚点**可消耗 1 根拴绳延长 1 倍距离（最多 4 倍）

### 剪断返还
剪断绳子时按延伸倍率返还对应数量的拴绳
2 倍长返还 2 根，4 倍长返还 4 根

### 悬挂物品
主手持可悬挂物品（灯笼、告示牌、方块），副手持线
右键绳子即可悬挂
可切换方块/物品显示模式

### 剪断
剪刀右键绳子 → 剪断并掉落
剪刀右键栅栏结 → 剪断结上所有绳子

### 滑索
手持锁链右键绳子即可开始滑索骑行。

# 概述
WMP 是一个围绕 **西瓜发电**、**玩家能量池** 与 **无线供能构建** 的工业辅助模组。
玩家可以通过 **西瓜发电机** 持续产出能量，并将能量汇入个人能量池。绑定后的机器可直接从玩家能量池中获取供电，无需传统布线即可维持运行。
同时，模组还支持为玩家背包、护甲栏、副手栏以及部分扩展栏位中的可充电物品进行无线充电。

# 内容
## 西瓜发电机
- 模组提供 西瓜发电机 作为主要产能设备；
- 发电机工作后会将能量计入对应玩家的玩家能量池中；
- 它不仅是发电来源，也是整个模组的起点。

## 玩家能量池
WMP 采用完全独立的**玩家能量池**系统，玩家获得的电力会统一汇总和管理，用于后续机器运行与物品充电。

- Hostile Neural Networks；
