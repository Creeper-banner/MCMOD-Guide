MC百科原则上欢迎上传所有真实存在的整合包，鼓励整合包作者自由创作天马行空的想象~  
  
整合包是将安装了多个模组并发布分享的 Minecraft。  
  
**整合包类型**有两种：使用[魔改模组](https://www.mcmod.cn/modlist.html?category=21)或自制模组对游戏内容或玩法进行或多或少的自定义修改的整合包称为“魔改整合”，反之为“原生整合”。  
  
根据不收录标准第 4 条（见下），MC百科不收录带有 Minecraft 本体的文件的整合。为此，有多种**整合包形式**：  

- CurseForge 托管：不带绝大多数模组，需要启动器从 CurseForge 下载所需模组的整合包。
- FTB 整合包：在FTB启动器中提供的整合包。
- Modrinth 托管：不带绝大多数模组，需要启动器从 Modrinth 下载所需模组的整合包。
- ATLauncher整合包：在ATLauncher启动器中提供的整合包。
- 启动器导出打包：使用启动器“导出整合包”功能导出的整合包。
- 手动精简打包：由整合包作者手动只把 mods 、config 等关键文件夹压缩发布的整合包。  
### **以下内容会作为“不收录”的评定标准：**  

- 含有违法内容、涉及时政内容、或是易引起社区矛盾对立的整合包；
- 含有不符 [百科模组收录规则](https://bbs.mcmod.cn/thread-3036-1-1.html) 的模组的整合包；
- 模组数量（去重后）少于 30 个的**原生**整合包；
- 含有分发 Minecraft 本体文件等违反 [Minecraft EULA](http://www.mcmod.cn/jump/aHR0cHM6Ly9hY2NvdW50Lm1vamFuZy5jb20vZG9jdW1lbnRzL21pbmVjcmFmdF9ldWxh) 的行为的整合包；
- 含有分发启动器的整合包；
- 仅对少量物品进行无意义合成修改或存在大量数值严重不平衡修改的低质量魔改整合；
- 仅无脑堆砌模组的低质量原生整合；
- 含有木马、窃取磁盘敏感信息等会对玩家造成严重危害的整合包；
- 含有恶意占用资源、后门等会对服务器运营者造成严重危害的整合包；
- 含有的 mod 文件含有其它网站推广信息；
- 以服务器宣传为目的的整合包；
- 整合包主要开发者一年内在百科或其他MC社区造成严重负面影响或重大争议；
- 整合包提供的相关链接会因整合包的更新而变动；
- 未完工且可实际游玩内容较少的整合包。  
    
  
### 整合收录条件  
#### 整合收录评价体系1，其中一条：

- 在 Modrinth 或 CurseForge 上的下载量达到 10,000 次；  
     
#### 整合收录评价体系2，对以下项目综合评分：

- 是否清理整合包冗余文件；
- 整合包是否使用 CurseForge 或 MCBBS 格式；
- 整合包是否具有显著特色；
- 整合包中魔改内容的质量与规模；
- 整合包是否含有任务、手册引导及其质量；
- 整合包平衡性是否合理；
- 若将百科作为首发站点，还需对整合包封面、正文、是否上传模组列表进行评定。  
  
#### 整合包元素及其定义见下表：  

| **元素名称** | **元素定义**                    |
| -------- | --------------------------- |
| 科技       | 含有科技类模组                     |
| 魔法       | 含有魔法类模组                     |
| 冒险       | 添加各种添加了新群系、新维度的模组，供玩家探索、冒险  |
| 建筑       | 加入了各种建筑辅助向模组，以搭建建筑为主要玩法     |
| 地图       | 含有整合包专属地图                   |
| 任务       | 含有任务引导                      |
| 硬核       | 游戏难度相对较高，包含了多且难的合成修改        |
| 休闲       | 游戏难度相对较低                    |
| 大型       | 占据主要玩法的核心模组数量较多             |
| 轻量       | 占据主要玩法的核心模组数量较少             |
| 剧情       | 含有整合包专属初始剧情或完全按剧情走向发展       |
| 水槽       | 没有独立主题，模组多且杂，无魔改或仅进行少量平衡性魔改 |
| 空岛       | 为空岛、海岛等不生成矿物的地图，矿物不靠挖矿获取    |
| PvP      | 以玩家对战为主要内容                  |
