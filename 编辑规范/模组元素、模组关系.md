## 模组元素
> 索引：  
> 问1：什么是模组元素？
> 问2：模组元素各自的定义是什么？  
> 问3：“核心元素”的优先级是什么？  
  
  
### 问1：什么是模组元素？  
- 答1：模组元素是用于分类MOD的一种方式，可在[此链接](https://www.mcmod.cn/class/category/1-1.html)内按元素筛选MOD。  
  
### 问2：模组元素各自的定义是什么？
- 答2：  
  
|          |                                                                       |
| -------- | --------------------------------------------------------------------- |
| **元素名称** | **元素定义**                                                              |
| 科技       | 设定可在现实中找到相关原始理论，且不满足冒险元素的定义，如电力、热力学、工程学、基因、量子、引力等内容。                  |
| 魔法       | 含有架空的世界观，且不满足冒险元素的定义，如魔力、法术、符文、祭坛、结界等内容。                              |
| 冒险       | 整个模组以添加挑战性与战斗元素，或是提高游戏生存难度为主，侧重点为增加新的怪物、提供给玩家武器装备、地牢、迷宫、世界等内容，或是模拟经营。 |
| 农业       | 以农业、林业、畜牧业或是增强饮食为主要内容的 Mod。                                           |
| 装饰       | 模组中多数物品/方块只可作为建材/装饰，没有互动，或是模组以使世界变得更美观为主。                             |
| LIB      | 单独安装不会增加游戏内容，仅为开发者提供 API 为主的模组，一般作为一些模组的前置。                           |
| 魔改       | 以提供给服务器管理人员或整合包作者自定义修改玩法的功能为主的 Mod，例如自定义合成表、物品、世界生成器等。                |
| 实用       | 未包含世界观的实用性 Mod，例如脑洞大开、小物件等，或是仅在依赖其他模组的基础上进行追加。                        |
| 辅助       | 整个模组的重点在于脚本，主要使用 GUI/按钮或指令来实现功能，通常未添加新的物品/方块。                         |
| 资源       | 含有自然生成的矿石、液体、花卉等涉及到世界生成器的材料。                                          |
| 世界       | 含有新的维度 (Dimension)。                                                   |
| 群落       | 含有新的生态群落 (Biomes)。                                                    |
| 生物       | 含有新的含AI实体，例如怪物或 NPC (Mobs)，包括对现有实体的衍生，例如村民，不包括仅对现有实体的修改。              |
| 安全       | 以提供保护玩家生命或财产安全为主要内容的 Mod（非武器/装备/爆炸物），例如提供账户登录、防止死亡掉落、保险箱等。            |
| 能源       | 含有自己的能源单位，或 Mod 中设备需要其他能源单位供能。                                        |
| 存储       | 含有可存储物品、流体、气体、数据、自定义物质等玩法内容的容器，或是为这些玩法内容提供了新的储存方式。                    |
| 物流       | 含有管道或类似管道，可协助其他模组实现自动化的元素。                                            |
| 道具       | 含有盔甲、饰品、工具或武器。                                                        |
| 红石       | 提供能够显性操作红石信号的内容。                                                      |
| 食物       | 含有可以恢复饥饿值/饱和度或能给玩家带来效果的食品。                                            |
| 模型       | 含有大量、复杂或是令人印象深刻的第三方模型。                                                |
| 指南       | 含有介绍自身 Mod 的书籍或是为其他模组提供有说明书性质的内容。                                     |
| 破坏       | 含有破坏方块的新方式。                                                           |
| Meme     | 以模因、梗、表情包等现象级行为为主的 Mod。                                               |
| 中式       | 含有强烈中国文化风格的模组。                                                        |
| 日式       | 含有强烈日本文化风格的模组。                                                        |
| 西式       | 含有强烈西方魔幻、神话故事色彩的元素。                                                   |
| 恐怖       | 以营造视觉上的恐怖为主的模组，常用手法如黑暗的/血腥的画面、诡异的音乐、毛骨悚然的特效、Jump scare 等。             |
| 建材       | 模组中添加了大量只可作为建材或装饰的无实际用途物品/方块。                                         |
| 生存       | 修改了原版的开局规则，例如改变玩家生命值或定义、禁用原版配方、改变原版物品材质或特性等。                          |
| 指令       | 增加了新的游戏内指令（命令）。                                                       |
| 优化       | 对原版或其他模组进行了性能上的优化，试图提高运行速度或减少 CPU/GPU/内存/带宽等硬件资源占用。                   |
| 国创       | 模组主要参与者来自中国大陆、港澳台。                                                    |
| 结构       | 含有新的自然生成建筑或遗迹结构，例如地牢、水井、神庙、高塔、祭坛、巨型石柱、传送门框架等。                         |
| 关卡       | 含有可供玩家挑战的解谜关卡设计，例如副本、迷宫、BOSS房间、寻找钥匙或密码等。                              |

  
### 问3：“核心元素”的优先级是什么？
- 答3：LIB > 魔改 > 辅助 > (科技 ? 魔法) > 冒险 > 农业 > 装饰 >  实用  
> 注：模组中若同时含有“科技”与“魔法”定义的内容，则根据模组实际所提供的内容比例来综合评定主要元素，如难以评定，可跳过科技/魔法来按后面的元素评定。

## 模组关系
> 索引：

### 问1：什么是模组关系？
- 答1：模组关系是用来确定模组之间的依赖，例如在安装某些模组之前必须先安装另外的模组，否则不能启动游戏，或是在游戏中模组之间可以协作完成一些事情。  
  
### 问2：模组关系的定义是什么？
- 答2：模组关系分为三种：**前置**、**拓展**、**联动**。  
  - **前置**、**拓展**：若A模组必须依靠B模组才能启动游戏，则B模组是A模组的**前置**，A模组是B模组的**拓展**。  
  
  > 为了方便理解，将模组带入：  
  > 若 [更多蜜蜂] 必须依靠 [林业] 才能启动游戏，则 [林业] 是 [更多蜜蜂] 的前置，[更多蜜蜂] 是 [林业] 的拓展。  
  > 若 [匠魂2] 必须依靠 [地幔] 才能启动游戏，则 [地幔] 是 [匠魂2] 的前置，[匠魂2] 是 [地幔] 的拓展。  
  
  - **联动**：若A模组作者为B模组写了专有代码，则A模组(主动)与B模组(被动)联动。  
  
  > 为了方便理解，将模组带入：  
  > 因为 [匠魂2] 为 [龙之研究] 新增了只有在安装了 [龙之研究] 时才会显示的物品"龙之碎片"，所以 [匠魂2] (主动)与 [龙之研究] (被动)联动。  
  > 因为 [林业] 引用了由 [工业时代2] 所提供的能源"EU"，而添加了"电力引擎"，且 [工业时代2] 中的"半流质发电机" 为 [林业] 写了支持 "生物质" 与 "乙醇" 的支持，所以 [林业] (相互)与 [工业时代2] (相互)联动。  
 
### 问3：模组关系的优先级是什么？
- 答3：前置与拓展 > 联动。
